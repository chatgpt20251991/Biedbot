BiedBot Edge · 0.2.0-pilot.1

De app is gebouwd.
Begin met de gesprekken.

De nieuwe lokale productrichting blijft staan. De gespreksmotor heeft weer een aparte Claude-schrijver, met de bedragen en veiligheidsbeslissingen in de code.

Dit bestand is de handleiding, niet de draaiende app.
De ZIP bevat de echte server, worker, interface en broncode. Automatische Marktplaats-verzending is niet geactiveerd. Start de applicatie met de bestanden hieronder.

Open de app op Windows

Eerste installatie

Pak de hele ZIP uit. Sluit een oude BiedBot-agent via de app af en maak bij bestaande gegevens een volledige backup. Dubbelklik daarna:

INSTALLER_BiedBot.cmd

Open de bureaubladsnelkoppeling, vul je bedrijfsprofiel in en ga naar Gespreksstudio.

Node staat al op je computer

Bij Node.js 22.16 of hoger kun je rechtstreeks starten met:

START_BiedBot.cmd

Geen npm-installatie nodig. Buiten Windows werkt ook npm run demo. De lokale URL verschijnt in de terminal.

De bestaande Windowsinstaller is behouden. De nieuwe versie en nieuwe Claude-launcher zijn in deze bouwomgeving niet op Windows uitgevoerd. Schakel beveiligingssoftware niet uit als iets wordt geblokkeerd.

Laat Claude echt schrijven

Sluit de agent af via Agent & controle → Agent afsluiten. Dubbelklik START_MET_CLAUDE.cmd, bevestig het gebruik en voer je eigen Anthropic API-sleutel afgeschermd in. De sleutel wordt niet in een bestand opgeslagen. Dit activeert betaald API-gebruik voor classificeren en schrijven, niet live Marktplaats.

Zonder deze activering blijft de app bruikbaar in offline stand. Die berichten worden zichtbaar als offline gelabeld. De echte API-client is gebouwd en met geïnjecteerde HTTP-responses getest; er is tijdens deze bouw geen echte Claude-aanroep gedaan.

Twee werkstanden in de studio

Oefenen

Speel zelf de verkoper. Probeer “Ik krijg een leaseauto”, “Wat bied je?” of “Voor 8000 mag je hem ophalen”. Je ziet de reactie, beslisfase, het juiste bod, het plafond en de tekstherkomst.

Handmatige concepten

Begin een nieuw eigen gesprek. Kopieer een concept en verstuur het zelf. Bevestig daarna pas Ik heb dit zelf verstuurd. Een gewijzigde tekst of reeds lopende externe onderhandeling moet je zelf overnemen. Kopiëren is geen verzendbewijs.

Een concept verloopt na maximaal vijftien minuten. Met Opnieuw schrijven maak je een nieuw concept op dezelfde beslisbasis. Die actie kan bij een ingeschakelde provider opnieuw API-kosten veroorzaken.

De daadwerkelijk gebouwde interface

Eigen broncode, gerenderd in Chromium. De getoonde verkoper is fictief en de berichten zijn offline-uitvoer. De afbeelding is geen bewijs van live platformtoegang.

Geen oude berichten die toch nog weggaan

De code bindt een concept aan de bronreactie, financiële instellingen, bevestigde gespreksstaat en teksthash. Nieuwe input, overname, noodstop, verval of gewijzigd beleid maken oude concepten ongeldig. Een onzekere verzending wordt niet blind herhaald. Financiële wijzigingen zetten lopende onderhandelingen in review.

Dit zijn concrete vangnetten, geen algemene belofte dat alle Nederlandse taal waterdicht wordt begrepen. De handmatige werkstand kan niet controleren wat je daadwerkelijk op een andere website typt of verstuurt.

Bestanden: README.md voor gebruik, docs/RELEASE_STATUS.md voor vrijgave, reports/communication-rebuild voor bewijs. Sourcecode staat in src, tests in tests. Er is geen externe Codex-taak of GitHub-publicatie uitgevoerd voor deze versie.
